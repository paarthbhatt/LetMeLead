# LetMeLead: the evidence desk

The memorable element is an original 3D instrument that turns scattered evidence into an inspectable lead. Everything else stays legible and quiet. No cloned competitor assets, fake logos, results, endorsements or staffed-service promises.

## Tokens
- Paper `#f4f6fa`, ink `#15171c`, panel `#ffffff`.
- Signal blue `#517be8`, evidence amber `#d49a39`, muted slate `#68717f`.
- Manrope: 72–88px hero, 40px sections, 16px body. Sentence case. Left aligned, reading lines under 75 characters.
- Soft instrument geometry; restrained 14px panels. Borders distinguish controls, not decorative card grids.

## Composition
```
brand / workflow / signals / agents       sign in / create workspace
clear product headline        original evidence sorter in 3D
short explanation + CTA       collect → qualify → review controls
interactive sample dossier + use-case selector
real signals → real evidence → controlled outreach
agent integration / credits / limitations / FAQ
one final invitation
```

Server-render the information. Native scrolling, keyboard-operable demo, labeled sample data. One lazy Three r187 canvas enhanced with WebGPU/TSL and WebGL2 fallback; static equivalent on mobile, reduced motion or renderer failure. Motion 14.9 for action-driven DOM transitions only. No scroll hijacking or perpetual decorative loops.
